## How to Use These Templates

Each template includes:
1. **Overview** — What the pipeline produces and target output format
2. **Tool Requirements** — Which AI tools you'll need (with free alternatives noted)
3. **Step-by-step Workflow** — From script to final export
4. **Prompt Examples** — Real prompts tested in production
5. **Estimated Time & Cost** — Realistic production timeline and budget
