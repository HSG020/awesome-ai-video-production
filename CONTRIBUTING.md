# Contributing to Awesome AI Video Production

Thank you for your interest in contributing! This project thrives on real-world production experience from the community.

## How to Contribute

### Adding a Tool or Resource

1. Fork this repository
2. Add the tool to the appropriate section in `README.md` (and `README_CN.md` if you can)
3. Include:
   - Tool name with link
   - What it's best for (1 sentence)
   - Pricing info
   - Your honest quality assessment based on actual usage
4. Submit a Pull Request with a clear description

### Sharing a Workflow Template

1. Create a `.md` file in the `/templates` directory
2. Follow this structure:
   - **Overview**: What the pipeline produces
   - **Prerequisites**: Tools and accounts needed
   - **Step-by-step workflow**: Detailed instructions
   - **Prompt examples**: Real prompts you've used
   - **Tips & gotchas**: What you learned the hard way
3. Submit a PR

### Sharing a Tutorial or Case Study

1. Create a `.md` file in the `/tutorials` directory
2. Include real examples, screenshots (if possible), and honest assessments
3. Submit a PR

## Quality Standards

We value **real production experience** over promotional content:

- Only add tools you've actually used in production
- Be honest about limitations — "great for X but terrible for Y" is more helpful than pure praise
- Include specific tips that save time, not generic descriptions
- If a tool has gotten worse or better recently, note the version/date

## Style Guide

- Keep descriptions concise and practical
- Use tables for tool comparisons
- Include pricing info (even approximate) — creators need to budget
- Add both English and Chinese content when possible
- No affiliate links

## Code of Conduct

- Be respectful and constructive
- No promotional spam or self-promotion without real value
- Credit original sources and creators
- Keep discussions focused on production experience

## Questions?

Open an issue with the `question` label and we'll get back to you!
